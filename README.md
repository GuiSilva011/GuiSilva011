Sobre mim
Sou Guilherme Silva, freelancer em desenvolvimento web. Desenvolvo sites e aplicações, trabalhando com interfaces, APIs e integração com bancos de dados.
Uso React, Node.js e Python, além de AWS, Linux e Docker para a infraestrutura. Também tenho interesse em DevOps e integração de IA em serviços.
