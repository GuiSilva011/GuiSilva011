## 01 / SOBRE MIM

Atuo no desenvolvimento de aplicações web, trabalhando com interfaces, APIs, bancos de dados e integrações.

Minha stack passa por **React, Node.js, Express, Python e PostgreSQL**, além de ferramentas como Docker, Linux e serviços da AWS.
