## Sobre mim

Sou **Guilherme Silva**, freelancer na área de desenvolvimento.

Trabalho com desenvolvimento web utilizando Python, Node.js e React, combinando interfaces objetivas, APIs, bancos de dados e ferramentas de infraestrutura para transformar ideias em soluções funcionais.

Este perfil reúne projetos, experimentos e tecnologias que fazem parte do meu processo de desenvolvimento.
