4. Abra Actions > Atualizar perfil > Run workflow.

O workflow cria a branch output e atualiza os SVGs diariamente.
A cobra e os cards aparecem após a primeira execução bem-sucedida.

on:

concurrency:
  group: profile-assets

jobs:
